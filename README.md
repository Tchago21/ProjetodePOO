O projeto se baseia no desenvolvimento de um sistema para simular o funcionamento básico de uma locadora de veiculos. O objetivo dele 
é permitir o cadastro e o gerenciamento de clientes, carros, motos, locações e pagamentos baseados no valor da diaria. Se um veiculo 
foi alugado por alguém, ele se torna indisponivel no sistema de locação ate que ele seja devolvido. O projeto é implementado em Java
e utiliza banco de dados em MySQL.
